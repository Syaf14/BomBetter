📖 How to play

The goal

Defuse every module on the bomb before the timer runs out. Too many wrong moves (strikes) and it explodes. You need 3 players, and each one is missing a sense, so you must work together.

The 3 roles

  • 🙉 Deaf sees the bomb but hears nothing. Describe what you see to Blind and Mute (speak, or type to speak), and chat with Mute in text.
  • 🤐 Mute has the manual and can hear, but can only type. Look up what Deaf describes and text back the answer. The manual rules are random every game.
  • 🙈 Blind touches the bomb but sees only a dark screen with unlabeled pads. Listen to Deaf, then press, cut or hold exactly what you are told.

How a round goes

  1. Deaf looks at a module and tells Mute what it shows, e.g. "3 wires: red, blue, yellow".
  2. Mute finds that module in the manual and texts the rule, e.g. "cut the second wire".
  3. Deaf tells Blind: "module 1, cut wire 2".
  4. Blind switches to that module with ◀ ▶ and does it. Listen for sounds: a good click, a strike buzz, or a "solved" chime.

Tips

  • Blind: pads are counted left to right, and the game says the module number aloud when you switch.
  • Mute: press X for the emote wheel to show numbers, yes or no with a big hand.
  • Keep talking. Say which module you mean every time.

Starting

  • Host a game makes a room. Share the 4-letter code with two friends, then everyone picks a different role.
  • Join enters a friend's room code.
  • Solo test shows all three roles on one screen so you can learn the game alone.

The host's browser runs the game, so keep that tab open.

🎬 Example gameplay

Example only. Your manual's rules are random every game, so the answers will differ.

Setup

A bomb with 4 modules and a 5:00 timer. Deaf sees the serial number is K7Q3M.

Module 1: Wires (a clean solve)

🙉 Deaf → Mute (text): "Module 1, Wires. 3 wires: red, blue, yellow. Serial ends in 3."
🤐 Mute: opens the "3 wires" section. The first true rule says "If there are no black wires, cut the second wire." Texts: "No black, so cut the second wire."
🙉 Deaf → Blind and Mute (voice): "Module 1, cut the second wire."
🙈 Blind: is on module 1 (the game says "Module 1"). Taps the second pad, hears the solved chime and says "Cut. Next module?"

Module 2: Keypad (a strike, then recovery)

🙉 Deaf → Mute: "Module 2, Keypad. Symbols: star, heart, skull, anchor. Positions 1 to 4 are star, skull, anchor, heart."
🤐 Mute: finds the one column with all four. Order top to bottom: anchor, star, heart, skull. Texts: "Anchor, star, heart, skull."
🙉 Deaf → Blind: "Module 2. Press 3, then 1, then 4, then 2."
🙈 Blind: presses 3 (lit, good), then 1 (lit, good), then 2 by mistake. Buzz! A strike ✖.
🙉 Deaf: sees the strike counter go up. "Strike. Keys 3 and 1 are done. Next is 4, then 2."
🙈 Blind: presses 4, then 2. Solved chime.

The end

After the other two modules are solved before the timer hits 0:00, everyone sees ✅ BOMB DEFUSED. If the timer ends or strikes run out, it is 💥 BOOM.

TAKE NOTE

1 strike make the bomb timer FASTER. More strikes, more FASTER to 💥 BOOM.

Good habits

  • Always say the module number first.
  • Blind: say what you pressed after each action ("pressed 3").
  • Deaf: say "strike" out loud so Mute can re-check the manual.
🧩 Module guide: what each role does

Tap a module to expand it. The bomb also shows a serial number (S/N), a battery count and indicator lights. Deaf reads these out when the manual asks for them.

✂️ Wires
  • 🙉 Deaf: count the wires and read their colors from top to bottom. Also tell Mute the serial number's last digit if asked.
  • 🤐 Mute: open the "Wires" section for that wire count and follow the first rule that is true. Text back which wire to cut, e.g. "second wire".
  • 🙈 Blind: you have one pad per wire. Tap the pad in the position Deaf says, counting from the first. A cut wire cannot be undone.
🔴 Big Button
  • 🙉 Deaf: tell Mute the button's color and word, then battery count and any lit indicators. If Blind has to hold, watch the strip color and say it. Then count Blind down to the right moment on the timer.
  • 🤐 Mute: follow the first true rule: tap or hold. If hold, text the strip's color to digit table result.
  • 🙈 Blind: there is one round pad. Tap = press and let go quickly. Hold = keep it pressed until Deaf says "release", which should be when the timer contains the digit.
🔣 Keypad
  • 🙉 Deaf: describe the four symbols (shapes only, e.g. "star, heart, skull, anchor") and say where each is (1 to 4).
  • 🤐 Mute: find the one column in the manual that has all four symbols. Text the order they appear in that column, top to bottom.
  • 🙈 Blind: four pads in a 2×2 grid, numbered 1 to 4. Press them in the order Deaf gives. A wrong press is a strike. Correct keys light up and are disabled.
🎵 Simon Says
  • 🙉 Deaf: watch the colors flash and call them out in order. The sequence repeats with one more flash each stage. Also tell Mute whether the serial number has a vowel and how many strikes there are.
  • 🤐 Mute: use the table for "vowel / no vowel" and the strike count. For every flashed color, text the color to press instead.
  • 🙈 Blind: four pads: top, right, bottom, left (red, blue, green, yellow). Listen to the pitches too: each position has its own tone. Press the translated positions in order, from the start each stage.
🧠 Memory
  • 🙉 Deaf: read the big display number and the four labels left to right. After each press, write down which position and label Blind pressed.
  • 🤐 Mute: use the table for the current stage and display number. It says a position, a label, or "same as stage N". Text the result.
  • 🙈 Blind: four pads in a row, positions 1 to 4 from the left. Press the position Deaf tells you. There are 4 stages. A mistake restarts from stage 1.
📡 Morse Code
  • 🙉 Deaf: a lamp blinks a word over and over: short = dot, long = dash. Read the blinks, and tell Mute the letters and the current frequency shown.
  • 🤐 Mute: decode the word with the Morse chart, find it in the table, and text the target frequency.
  • 🙈 Blind: three pads: left = lower frequency, middle = transmit, right = higher. Deaf says which way to go until the frequency matches, then press transmit. You can also hear the blinks as beeps.
