Put your game icon files in this folder with these exact names:

  favicon.png          32x32    browser tab icon
  icon-180.png         180x180  iPhone/iPad home screen (apple-touch-icon)
  icon-192.png         192x192  Android home screen / PWA
  icon-512.png         512x512  Android splash / PWA (also used as maskable)

Tips: use PNG, keep the important part of the artwork inside the centre ~80% so it
isn't cropped on round/rounded icons, and don't use transparency for icon-180.
Background colour used by the app is #0b0b0e.
